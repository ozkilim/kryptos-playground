# How K1–K3 work (the solved three)

All three are reproduced by `python solved/k1.py`, `k2.py`, `k3.py`, both with the known key **and blind** (the solvers find the key themselves). That's the proof the toolkit works.

## The Kryptos tableau

The right side of the sculpture is a Vigenère tableau built on a *keyed alphabet*: the word KRYPTOS first, then the rest of A–Z.

```
KRYPTOSABCDEFGHIJLMNQUVWXZ
```

`kryptos.ciphers.KRYPTOS_ALPHABET`. K1 and K2 use it; the solvers always try it alongside plain A–Z.

## K1: Vigenère, key PALIMPSEST (63 letters)

> BETWEEN SUBTLE SHADING AND THE ABSENCE OF LIGHT LIES THE NUANCE OF IQLUSION

* `vigenere_decrypt(ct, "PALIMPSEST", KRYPTOS_ALPHABET)`
* Too short for statistics: 63 letters at period 10 is ~6 letters per key column. The blind route is a **dictionary attack** (`python -m kryptos crack k1 --wordlist`): PALIMPSEST is an English word.
* IQLUSION is deliberate. The tableau also spells the key "PALIMPCEST".

## K2: Vigenère, key ABSCISSA (369 letters + 3 "?")

> IT WAS TOTALLY INVISIBLE HOWS THAT POSSIBLE? THEY USED THE EARTHS MAGNETIC FIELD … THIRTY EIGHT DEGREES FIFTY SEVEN MINUTES SIX POINT FIVE SECONDS NORTH SEVENTY SEVEN DEGREES EIGHT MINUTES FORTY FOUR SECONDS WEST X LAYER TWO

* Long enough for statistics: periodic IoC spikes at 8, chi-squared picks each key letter, quadgram hill-climb polishes it. `python -m kryptos crack k2` finds ABSCISSA blind.
* The "?" are unenciphered punctuation and don't advance the key.
* **Sanborn's error:** an S was left out near the end, so the carved text decrypts to "…WEST ID BY ROWS". In 2006 he said it should read "…WEST X LAYER TWO". Both versions are in `data/sculpture/k2.json`.
* UNDERGRUUND is deliberate.

## K3: double rotation transposition (336 letters)

> SLOWLY DESPARATLY SLOWLY THE REMAINS OF PASSAGE DEBRIS … CAN YOU SEE ANYTHING Q

Paraphrases Howard Carter opening Tutankhamun's tomb (1922).

* Letters are unchanged, only moved: IoC 0.066 and English letter frequencies give it away (`python -m kryptos triage k3`).
* Method: write the ciphertext in rows 24 wide, turn the grid 90° clockwise, re-cut to rows 8 wide, turn again, read off. `rotation_decrypt(ct, 24, 8)`. Several width pairs are equivalent (4/48, 8/24, 16/12 all work).
* Blind: `crack_rotation` tries every width pair that divides 336.
* The "?" carved after K3 isn't one of its 336 letters. K4 starts right after it.

## Who solved them

NSA analysts solved K1–K3 privately in the early 1990s. CIA analyst David Stein solved them by hand (published internally, 1998), and Jim Gillogly published them in 1999. K4 has been open since 1990.

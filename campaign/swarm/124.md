# Idea 124: sentence keys, grown outward from the clues

**Verdict: no signal (low-power test).** K4's best setting tops the noise range, but neither of its strings is
English. The method itself turned out weak: the beam makes both strings look English for almost any setting.

## The idea

Ideas 57, 65 and 89 tested "the key is an English sentence, on a keyword tableau" by scoring only the 13 + 11 key
letters the clues force. Here each candidate setting is also asked to keep going. Every plain letter after a clue fixes
the key letter there, so plain and key are grown together, letter by letter, across the 29 unknown letters to
BERLINCLOCK. The beam scores the plain string plus the key string on the big quadgram model. A true setting should
keep both strings English all the way. Noise should not manage that.

## What was run

`attacks/124_grow_key_and_message.py` (helpers in `kryptos/idea124_grow.py`). The main run took 31 minutes and the
matched K4 thirds another 30.

* **Stage 1:** 807,745 alphabets (dictionary keyword alphabets, their two transposition mixes, and idea 89's non-keyword
  orders) x 5 layouts x 4 forms x 78 key readings (A-Z, M or KRYPTOS at s+c). That is 1.26 billion settings, and the
  best 20,000 by forced key letters were kept.
* **Stage 2:** a width-20 beam over the gap for all 20,000, then width 300 plus 12 letters on each side for the best 200.

## Numbers

| K4, all alphabets | -8.069 | 19,905 / 20,000 |

| shuffled K4 #1 / #2 / #3 (same thirds) | -8.222 / -8.260 / -8.277 | 19,500-19,625 |
| K4, 20,000 random settings | -8.768 | 77 |

K4's best (ANGIOPLEROSIS, A-Z/M, Beaufort, key read KRYPTOS+5; stage-1 rank 1):
plain `LPARTSALMARGEASTNORTHEASTERSIONCONSSTHANGINGANOTHETFORBERLINCLOCKSENTHEINDTHE`,
key `THESARENTISAVEONDERSGEUSAGINSERVERSTHETHESAREFORFORESSAARESEXISFONETHESSANDIE`.
Both are quadgram soup, not English. In the matched comparison K4 beats its shuffled third twice (by 0.03 and 0.21)
and loses once. One maximum 0.17 above the other five noise maxima, with unreadable text, is not a signal.

## Planted answers

These were six keys: attack 57's four, idea 89's key that ranked 7th, and a key made of rare dictionary words. Stage 1 kept
every one (pool rank 0-2; against K4's full run they would rank 0-141 of 20,000). After the beam, 3/6 ranked first in their
own pool, but only 2/6 (true joint -8.015 and -7.963) beat the best full-scale noise (-8.069). Idea 89's hard case
is still lost (rank 12, -8.476).

## What was surprising

The "bridge" criterion is useless as stated. 98-99.5% of kept noise settings bridge, because one free plain
letter per position is enough for a quadgram beam to make both strings English-looking: noise scores -3.8/-4.4 per
quadgram, while the true texts themselves score only -4.0 to -4.9. The beam also finds strings that score better
than the truth on true settings. So the beam is not more decisive than the 24-letter score. It just moves the
problem: noise maxima sit at -8.07 to -8.28, true settings at -7.96 to -8.48.

## Scope limits

The test has low power (2/6 planted keys clear the noise). Only the listed alphabets, layouts, forms and readings were
searched. German keys, non-word or numeric keys, and wrong clue letters are not covered. A stronger language model
(word-level or 5-gram) would be needed to make this test decisive.

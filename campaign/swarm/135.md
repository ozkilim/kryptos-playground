# Idea 135: cipher-fed state device with a keyword side

**Verdict: dead in scope** (both sides keyword alphabets); one side hidden **cannot be judged** for most alphabets.

## The idea

A device keeps a number s mod m. For each letter it writes `C = F(s + h(P))`, then moves on by `g(C)`, an amount
set by the cipher letter it just wrote. Idea 83 found that with F, g and h all hidden this fits every m >= 14. The
hope was that fixing one table to a keyword alphabet leaves about 8 exact equations.

## What the equations say

K4's 22 fed clue letters repeat 8 times (F, R, V, Q, N, T twice, P three times), so there are 8 equations. But with
one side known they hold 13 (F hidden) or 12 (h hidden) unknown places. They have full rank under every modulus, so
**0 linear checks** are left. All that can bite is that different letters need different values. Only with **both**
sides known (only g hidden) are the 8 equations real checks. Each check splits into one value from the cipher
alphabet and one from the plain alphabet, so a hash join tests every pair of alphabets at once. Idea 83 had only
tested the same alphabet on both sides.

## What was run

`attacks/135_cipher_fed_keyword_side.py`, 7.5 minutes, 666,993 alphabets, m = 26..31.

| | K4 | shuffled #1 / #2 / #3 |
|---|---|---|
| equations | 8 | 11 / 8 / 8 |
| F hidden, h keyword: alphabets that fit | 53-59% | 0.6% / 2.0% / 2.9% |
| h hidden, F keyword: alphabets that fit | 88-90% | 33-48% / 100% / 79-82% |
| both keyword, hits (5.34e12 pairs) | 17 (chance 13.9) | 0 / 6 / 21 |
| best reading, big model | -5.689 | - / -5.984 / -5.472 |

* Every "fit" was re-checked by running the device; every "impossible" is a proof. Nothing was left undecided.
* K4's best reading: `PTEDLLCLZZGVUWOAENFDYEASTNORTHEASTANDNYBDKSTINSSPA...` (ORNITHUROUS / ROUTINE~keyed, m=26).
  This is noise. English needs -5.1, and one control scores better.
* Planted, 5/5. With both sides known, 2/2 devices (m=26, m=29) were found among 9,000 x 9,000 alphabets and read
  back 93/97 and 97/97, ranked first. With one side known, the true alphabet fits 3/3, but so do 5,519, 0 and 4,414
  of 9,000 decoys.

## Scope limits

* With one side hidden, the alphabets that pass the distinct-values rule are not decided. That class stays open, as
  does the case with both sides hidden.
* Only the state moved by the cipher letter just written; one-to-one F only. m = 13 and 2 cannot hold a one-to-one
  F (14 different clue cipher letters).
* For m > 26 the full text must avoid values with no letter; only the readings check that.
* The readings come from a beam search with hill climbing. On 10 planted texts it read back 89-97 of 97.

## Surprising

* The idea's count of 8 equations was right, but they don't decide the case it was aimed at (one side hidden).
  They only decide the case with both sides known.
* How often the distinct-values rule kills an alphabet depends mostly on how the cipher letters repeat. On K4 it
  kills far fewer alphabets than on the controls (47% vs 97-99% with F hidden). That is a property of the text,
  not a signal.

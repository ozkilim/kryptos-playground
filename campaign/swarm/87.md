# Idea 87: free choice of system at every letter

**Verdict: dead in scope.** No K4 setting reaches the bar, or even the 5-check gauge. The shuffled K4s give the same nothing. All 4 planted answers were found and read back.

## The idea

There is one repeating key word. At each letter the encoder may use either of two (or three) systems: Vigenere,
Beaufort or variant Beaufort on one tableau, or the same form on two different tableaux. The point would be to
flatten the letter counts ("masked the English language", "two separate systems"). The reader tries both systems
at each letter and keeps whichever reads.

## What was run

`attacks/87_free_choice_per_letter.py`, with helpers in `kryptos/idea87_freeform.py`.

* **The test.** Each clue letter allows a *set* of 1-3 key values, one per allowed system. A repeating key fits
  only if, in every class mod L, the clue letters' sets share a value (a bitmask AND). A sliding key is the running
  sum of a repeating word; it is solved exactly by a depth-first search over the 24 clue letters.
* **Strength.** A set test is weaker than an exact one, so its strength is counted in exact-check equivalents:
  strength = -log26(26^free x prod |S_i|/26). The bar is 7, as in rounds 9-11.
* **Alphabets.** A-Z, KRYPTOS and 220,316 dictionary keyword alphabets, in the five layouts of idea 66.
* **Choice sets.** Four sets of forms: {V,B}, {V,var}, {B,var} and all three. Tableau choice: M against A-Z, and M
  against KRYPTOS, in one form each, plus Vig/Beau on both tableaux.
* **Key lengths.** Repeating L = 1-17 for every set. Sliding L = 1-17 for the form sets, only where strength >= 3.
* **Reading.** Anything at strength 5 or more would be decoded by a beam search on the big quadgram model. Nothing
  got that far.

The clue pre-filter gives PASS. One caveat: the "K5 same words, same places" mark passes only because the probe
reuses the same coin flips. A truly free encoder would break that firm statement unless it happened to choose the
same way both times. That counts somewhat against the idea.

## Scope limits

* **Decided only for short keys.** Strength 7 is reached at these key lengths (worked out from K4's actual clue letters):

  | Choice | Decided up to |
  |---|---|
  | 2-way, repeating key | L 11 (up to 14 on some alphabets) |
  | 2-way, sliding key | L 10 (up to 12) |
  | 3 forms | L 9 repeating, 8 sliding |
  | 4 systems | L 7 (up to 9) |

  Longer keys, up to 17, were run but are not decided. Keys above 17 were not run.
* **Alphabets.** Keyword alphabets only. No transposition-mixed, non-keyword or hidden alphabets.
* **Tableau choice.** Repeating key only, and only M against A-Z or KRYPTOS. The key letter is named on each
  tableau's own alphabet.
* **Not covered.** Autokey or running keys, transposition, and more than three forms.

## Anything surprising

* **The chance bound is loose.** It overestimates: at strength 3-5 it predicts 109 repeating passes, but K4 gives
  0 and the controls give 0-3 per third. So the 0 at the 7 bar is if anything conservative.
* **Weak, undecided band.** K4's 2,855 passes there are about 1.4-4 times the controls scaled to the full alphabet
  set (685, 226 and 340 per third). That band is weak, it swings a lot from control to control, and nothing in it
  reaches strength 3.
* **Three systems read worse.** In the smoke runs a sliding plant with all three forms read back only 81% of
  letters. That is natural ambiguity, because the reader has three candidates per place. Two-way plants read back
  90%+.

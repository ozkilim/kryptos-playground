# Idea 110: any linear rule for the key, tested without naming the rule

**Verdict: dead in scope.** K4 gives 0 passes in 2.21 billion exact tests, the shuffled K4s give 0 too, and all 9
planted rules were found and read back.

## The idea

Scheidt says the method is simple and can be run again from memory. Earlier rounds tested key rules by name
(progressive, chain addition with two taps, listed formulas). Here the rule is not named. If each key letter is a
fixed linear mix of the few before it,

    K[i] = a1 K[i-1] + ... + a5 K[i-5] + c   (mod 26)

then the 13 + 11 key letters forced by the clues must obey it inside each block for *some* a1..a5, c. That is 14
equations in 6 unknowns: 8 exact checks, solved mod 13 and mod 2. Order 5 contains every lower order, so one solve
covers polynomial keys to degree 4, chain addition with any taps and multipliers, generators a K + c, their sums,
and order 4 with a drift term e*i (take differences). The rule only looks back inside a block, so a wrong gap
between the clues cannot hide it. The clue pre-filter gives PASS.

## What was run

`attacks/110_any_linear_key_rule.py` (helpers in `kryptos/idea110_linear.py`, test in `tests/test_idea_110.py`).
Key streams: 666,993 alphabets (A-Z, KRYPTOS, dictionary keyword alphabets and their two transposition-mixed forms)
x 5 layouts x C-P and C+P = 6,669,928.

* **A** order 5 + constant, 8 checks. **A2** order 5 + drift e*i, 7 checks (needs the carved positions).
* **B** text-fed: K[i] = a1 K[i-1] + a2 K[i-2] + u P[i-s] + v C[i-t] + c, s, t = 1..6, P and C each numbered on the
  tableau alphabet, A-Z or KRYPTOS: 324 settings per stream, 7 to 15 checks.
* **C** not linear: K[i] = g(K[i-d]), g(P[i-d]) or g(C[i-d]) for an arbitrary table g. Equal inputs must give equal
  key letters; 7 forced repeats required. Judged for the text: plain 1 back (10 repeats), plain 2 back (8), cipher
  1 back (8), cipher 2 back (7).
* Gauges below the bar (order 6 at 5 checks; tables at 5-6 repeats) to see that chance behaves as predicted.

## Scope limits

* Keyword tableaux from the dictionary only, five layouts, mod 26. No hidden alphabet.
* Order 5 at most. Order 6 leaves 5 checks (gauge only).
* A constant that changes with position is covered only as a drift e*i. A periodic or word-driven constant is not.
* Text-fed rules: two key taps, one plain and one cipher letter, lags 1-6. Table rules: one input, and only lags
  with 7+ forced repeats (text lags 3-6 are not judged).
* The rule must run unbroken inside each clue block.
* Controls used a third of the alphabets each; planted texts were searched in a 1-in-40 sample.

## Surprises

None in the result. One useful fact: an order-4 rule with a drift term is an order-5 rule after taking differences,
so the "one more unknown" case in the plan was already inside test A and is immune to the gap as well.

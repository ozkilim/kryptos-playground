# Idea 84: two layers on two different tableaux

**Verdict: dead in scope.** K4 gives nothing at the 7-check bar, the shuffled K4s give nothing, and all 4 planted
answers came back as the single survivor.

## The idea

K2 ends LAYER TWO and Scheidt calls K4 "more than one stage". Every stacked-key test so far put both layers on the
same tableau, where two repeating keys add into one key stream. If layer one is on one alphabet and layer two on
another, the keys do not add on any alphabet, and none of the earlier exact tests can see it:

    Y = A[ +-A^-1(P) + a_(i mod p) ]     C = B[ +-B^-1(Y) + b_(i mod q) ]

`+` is Vigenere (variant Beaufort is the same with the key negated, and key letters are free here), `-` is Beaufort.
The clue pre-filter gives PASS (letters stay in place, same word at the same place encrypts the same, fixed points
allowed).

## What was run

`attacks/84_two_tableaux.py` (helpers in `kryptos/idea84_twotab.py`). Given A and B, each clue letter ties one
letter of key a to one letter of key b by a known one-to-one table. Guess one key letter (26 values), follow the ties;
every tie that closes a loop is a check. Checks = clue letters minus key letters, per connected piece, so chance
passes a setting with n checks about 26^-n of the time. No key is guessed and keys need not be words.

* **Alphabets.** Part 1: every ordered pair of different alphabets from A-Z, KRYPTOS and 84 theme-word alphabets
  (7,310 pairs). Part 2: 220,232 dictionary keyword alphabets, each against A-Z and against KRYPTOS, both orders
  (880,928 pairs). A = B is skipped (closed before).
* **Keys.** All 162 (p, q) up to 26 x 26 with 7+ checks: every p + q <= 17 (wider than the planned p + q <= 14 for
  the dictionary part), plus long keys the clues only partly touch (19-22 with a partner of 1-4). Another 57 (p, q)
  with 5-6 checks were run only as a gauge that chance behaves as predicted.
* **Types.** 4 (Vigenere or Beaufort per layer).

The controls ran part 1 in full and a different third of the dictionary alphabets each. K4's two gauge-level survivors
(KRYPTOS then FROGFOOT, p=19 q=4; KRYPTOS then MECHANOLATER, p=9 q=10; both Beaufort/Beaufort, 5 checks) decrypt to
gibberish with non-word keys.

Planted answers: **4/4**. Each was the only setting over the bar among 6.4M-19.3M searched, and the whole 97-letter
message was read back (English -4.18 to -4.64):

* KRYPTOS tableau, key SHADOW, then A-Z, key LANTERN
* BERLIN alphabet, key ABSCISSA, then WORLDCLOCK alphabet, key LODESTONE (Beaufort); p + q = 17, the edge of the range
* dictionary alphabet EPIGRAMMATISM, key BERLIN, then KRYPTOS, key ILLUSION (Beaufort)
* A-Z (Beaufort), key COMPASS, then dictionary alphabet POCKETED, key TUNNEL

## Scope limits

* Both alphabets must be on the lists. Two dictionary alphabets at once, transposition-mixed alphabets and hidden
  alphabets are not covered.
* p + q of 18 or more is not decided (too few checks), apart from the few long-key cases listed above.
* Repeating keys only: no autokey, progressive or running key in either layer, no transposition between the layers,
  no third layer, no gap slack.

## Anything surprising

No. The count of chance survivors at 5-6 checks (K4 2, shuffled 4, 1, 2) sits at or a little under the 26^-n
prediction, so keyword alphabets against A-Z or KRYPTOS do not pass more easily than random alphabets would, and the
0 at 7+ checks can be taken at face value (about 0.011 chance survivors expected over the whole K4 run). The test
is cheap: the full run (K4, three controls, four planted searches, about 1.6 billion settings) took 8 minutes of
the slot, so the mixed-alphabet extension in the follow-ups is affordable.

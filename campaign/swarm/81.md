# Idea 81: one deliberately wrong clue letter, for the round 9-11 exact tests

**Verdict: dead in scope.** K4 gives nothing, the shuffled K4s give nothing, and all 7 planted answers were found.

## The idea

Sanborn's texts carry deliberate misspellings (IQLUSION, UNDERGRUUND, DESPARATLY). If one of the 24 clue letters of
K4 is wrong in the same way, every exact test of rounds 9-11 fails on the true method, because those tests need all
24 letters to fit. Round 7 (attack 45) allowed one wrong letter only for periodic, two-key and Gromark models.

## What was run

`attacks/81_one_wrong_clue_letter.py` (helpers in `kryptos/idea81_dropone.py`). Each of the 24 clue positions is left
out in turn, and three exact tests are run on the 23 letters that remain:

| Test | Scope | Bar |
|---|---|---|
| Key-rule battery (`kryptos.round11.battery`: repeating, sliding, progressive, autokey, two stacked keys, chain addition) | 220,318 plain keyword alphabets x 5 layouts x Vigenere/Beaufort x 24 drops = 52,876,320 settings | 7+ checks |
| Multiplier word + adder word (attack 71 part A), C = A[i mod p] x P + B[i mod q] | p, q = 1..17, 4 A-Z/KRYPTOS views, 24 drops = 27,744 exact systems | 7+ checks |
| Rotor with hidden wiring turned by a word (attack 72, dictionary part) | 248,495 words x 3 schemes x 2 numberings x 4 face pairs x 2 directions x 24 drops = 286,266,240 tests | kept from 5 forced coincidences (as attack 72); 7+ is the headline |

For the rotor, only the wires in the first collision can be the one to drop, so the 24 drops cost about three wire
tests, not 24. A unit test checks this shortcut against trying every drop.

* 3 sliding-key messages on keyword alphabets (periods 8, 6, 6; wrong letter at 71, 30, 26)

339,170,304 settings on K4 in all. The whole run took about 27 minutes.

## Scope limits

* Exactly one wrong letter. Two or more are not covered.
* Only these three tests. Not covered: attack 72's constant speeds, letter-fed turning and exhaustive keys of length
  1-6; attack 71 part B; the transposition-mixed keyword alphabets; and the other round 9-11 tests (formula mining,
  hash joins, hidden-alphabet solves, evolving alphabets, keyed-lag autokey, arithmetic mod 27-31).
* Leaving a letter out also loses the links through it (its key difference to each neighbour), so the battery is a
  little weaker than on 24 letters. The planted sliding keys were still found with periods up to 8.
* To keep the run near half an hour, each shuffled K4 saw a different third of the alphabets in the battery (every
  third alphabet). The other two tests ran in full on every control.
* Each planted sliding-key message was searched on a 9,001-alphabet sample that includes the alphabet it was built on.
* Each test keeps the limits of its original attack (periods, lags, the 7-check bar).

## Anything surprising

No. Not one chance pass anywhere, in K4 or the controls, even though dropping a letter multiplies the number of
settings by 24. The 7-check bar still leaves the expected number of chance passes below one.

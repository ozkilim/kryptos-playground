# Idea 93: real word keys on a fully hidden tableau

**Verdict: dead in scope.** 0 of 295,227,813 settings fit.

## The idea

Scheidt says K4 runs "with the correct key word/s". Long keys on a hidden alphabet were listed as open, but only
because the key letters were unknowns too. If the key is a real word, a phrase from K1-K3 or a reading of the
sculpture, the key letters are known. One hidden alphabet is then just 26 unknown positions, and the 24 clue letters
give 24 linear equations in them mod 26. That is decidable at every key length.

In true Quagmire III (the key letter is found on the same hidden alphabet) K4's own oddities become filters on the key:
plain S gives cipher S at letter 33 and K gives K at 74, so the key letters at those two places must be the same
letter; R gives P at both 28 and 66, so those two key letters must also match. No earlier test used this.

## What was run

`attacks/93_word_keys_hidden_tableau.py`, helpers in `kryptos/idea93_hidden.py`.

* **Keys:** 264,828 words and phrases of 2-26 letters (theme words, common words, /usr/share/dict, every 4-26 letter
  window of the K1-K3 plaintexts), each at every phase, used as a repeating key, as a sliding key (running sum of the
  word) and as a progressive key (one step further at each pass). Plus the 224 distinct readings of attack 58 (rows,
  columns, back-and-forth, diagonals of both panels, K1-K3 plaintext grids, Morse), every d-th letter for d = 1-60:
  45,104 streams, 2,334,946 offsets, used as running keys.
* **Models:** (a) one hidden alphabet on both sides with the key valued on A-Z or KRYPTOS, C = P + k and C = k - P,
  any constant offset; (b) true Quagmire III in three forms (C = P + K, P - K, K - P), sliding with a free start and
  progressive with any step; (c) hidden plain or hidden cipher alphabet against A-Z or KRYPTOS, key added or
  subtracted, and true Quagmire II.
* **Test:** exact. A setting survives only if the equations have a solution mod 26 (mod 13 and mod 2 joined) in which
  the letters sit in different places. "All letters in one place" solves every such system, so plain consistency was
  never accepted. Survivors would be decrypted where forced and scored on the big English model.

For K4, 15.75M linear systems had to be solved in full; everything else died on the forced-equal key letters or on the
fixed dot products. "Undecided" are true Quagmire II settings with a running key that leave 5 or more free dimensions,
too many solutions to list. K4 had none.

**Planted: 9/9.** Random 26-letter alphabets, messages carrying the real clue words: Quagmire III with SCULPTURE (88 of
97 letters read back, English -4.18), with the 24-letter UNDERGROUNDTRANSMISSIONS (95, -4.51), sliding ILLUSION
(75, -4.95), progressive ABSCISSA (92, -4.34), a sculpture reading as running key (69, -5.37); numeric sliding KRYPTOS
(74, -4.47), SHADOW on KRYPTOS values (81, -4.59); Quagmire II with PALIMPSEST (71, -4.91); hidden plain alphabet with
BERLIN minus one per pass (78, -4.01). Each time the true key and phase were found among 2,000 other words and the
clue letters' positions came back (up to sliding or decimating the whole alphabet, which does not change the cipher).

## Scope limits

* One hidden alphabet. Two different hidden alphabets are not decidable this way.
* Only keys in the lists. No pairs of dictionary words, no German, no misspellings beyond the lists.
* Sliding and progressive keys were not run on Quagmire II. Numeric progressive keys used steps +1 and -1 only.
* Sculpture readings were used only as plain running keys.
* The clue positions are taken as exact.

## Worth knowing

* The run took 7 minutes, far less than planned, because the packed elimination costs about 50-100 microseconds a system.
* With zero survivors there was nothing to read, so the English score played no part for K4. The result rests on exact
  equations alone.
* Chance survivors do exist for other texts: the first planted message (no fixed points) let 75 of 2,000 decoy words
  through. K4 is harder to fit because of its fixed points and repeated pair. The shuffled controls keep the clue
  plaintext but mostly lose those coincidences, and still gave 0.
* The planted running key read back at -5.37, below the -5.1 bar used elsewhere. Had a running-key survivor appeared
  for K4 it would have needed a human read.

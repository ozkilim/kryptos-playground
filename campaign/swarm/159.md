# Idea 159: letter shapes, a stroke added or cut away

**Verdict: no-signal** (and dead inside the model that was tested).

## The idea

Sanborn cut the letters by hand. Seven of the 24 clue pairs are the same letter or one stencil stroke apart:
E->F, O->Q, R->P (twice), I->T, S->S, K->K. Perhaps at some places the cipher letter is just the plain letter
with a stroke added or removed, and an ordinary key covers the rest.

## What was run

`attacks/159_letter_shapes.py`, helpers in `kryptos/idea159_shapes.py`, 125 seconds, 76.7M settings counted.

**Part A, the statistic.** Three shape codings written out once: 16-segment display (one stroke = up to 2
segments), 5x7 dot matrix (up to 5 dots), a stroke list for block capitals (1 stroke). Six statistics (near
count and mean distance per coding), 100,000 pairings per control, one corrected p for the best of the six.

| control | expected near pairs (16-seg / dots / strokes) | K4 | corrected p |
|---|---|---|---|
| (i) same letters, random pairing | 2.5 / 2.2 / 1.9 | 7 / 8 / 7 | 0.0016 |
| (ii-b) any letter, same alphabet distance | 3.9 / 3.5 / 2.7 | | 0.0014 |
| (ii-c) same letters, same alphabet-distance profile | 4.3 / 4.0 / 3.7 | | 0.011 |
| (ii-a) same plain letter and alphabet distance, direction random | 5.5 / 6.0 / 5.0 | | 0.21 |

The gate fixed before the run was corrected p < 0.01 under (ii-c). K4 gives 0.0112 (four separate chains:
0.010 to 0.012). **Not passed.** Shape closeness is clearly above random pairing, but most of it goes away
once alphabet closeness is held fixed: three of the six one-stroke pairs of the alphabet (E/F, O/Q, P/R) are
also within two places of each other. The alphabet itself ties shape to Bean closeness, and 24 pairs cannot
pull them apart.

**Part B, the model** (run for the record, since it costs seconds).

* Near places (0-based) 21, 26, 27, 32, 65, 67, 73 (the dot matrix adds 29, H->N). They form no pattern:
  best every-p-th count 4 to 5, p = 0.76 / 0.26 / 0.76 against the same number of random places; no period
  2-13 splits near from not-near; carved columns (period 31) hold nothing.
* Masked places = residue classes mod 2-13 whose clue places are all near, rest under one repeating key of
  1-12 (Vigenere or Beaufort, A-Z or KRYPTOS strips, key numbered by position or by unmasked letters):
  **0 of 4,784** settings fit the clue letters.
* No pattern assumed, ANY set of near clue places masked: **0 of 362,408**.
* Every place a shape change: best readings -6.14 / -6.89 / -7.66 on the big model, word coverage
  0.28 / 0.16 / 0.16, e.g. `CDKALCXCCALLDSOUTEDDNELAVOORANSKSSOINTO...`. Not English; the clue words cannot
  appear (A->L is not a stroke apart).

So there is no decryption to judge: nothing survives the clue letters.

## Controls

* 200 shuffled K4s: near pairs median 3 / 2 / 1; as many as K4 in 3 / 0 / 0 of 200. No survivor in either
  exact test (but they have few near pairs, so only a median of 184 and 6,408 settings each).
* 200 texts with K4's own 24 clue pairs moved to random clue places, rest shuffled (same near pairs, same
  number of settings as K4): 0 of 200 with a survivor. Pattern count as high as K4's in 146 / 53 / 146.
* All-places-masked reading: 144 / 117 / 163 of 200 shuffles score at least as well as K4.

## Planted

36/36. English texts with one-stroke changes at every 3rd, 4th or 5th place and a repeating key of 4-8
elsewhere were found by both exact tests and read back with 0 to 4 wrong letters of 97 (the truth was the top
reading in 35 of 36). Part A flagged 31 of 36.

## Scope limits

* The codings were written after the idea had named the pairs, and the stroke list is one person's choice.
  Every p here is after the fact and so too small. R->P counts twice.
* Part B only covers one repeating key of length 1-12 at the unmasked places, with A-Z or KRYPTOS strips.
  A long or non-repeating key there cannot be tested by the clues at all, and is not ruled out.
* Not covered: two-stroke rules, serif or lower-case forms, Sanborn's actual letter shapes (no tracing in the
  repository), other keyword alphabets, transposition.
* Shape ciphers that apply one fixed operation to every letter (rotate, mirror, pigpen turns) need no run:
  the clue pairs link 21 letters into one chain and T goes to three different letters.

## Anything surprising

The effect against plain random pairing is real (p about 0.002, 0 of 200 shuffles reach K4's count in two
codings), and it does not vanish entirely under the matched control (0.011). But the tightest control, which
keeps each plain letter and its alphabet distance, explains it fully (0.21): given that E moves one place, it
becomes F or D; given that R moves two, P or T. The honest reading is that this is Bean closeness seen
through shapes, not the other way round. Pre-filter: FLAG. The model fails the firm statement "K5 has the same words at the same places" (a shared
word came out identical in only 55% of probe message pairs) and passes S->S / K->K and "matches directly".
It was built anyway because the whole test costs two minutes.

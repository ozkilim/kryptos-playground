# Idea 120: the K1/K2 machine as a known layer, then every key rule on a second tableau

**Verdict: dead in scope.** Nothing passes at 8+ checks. One coincidence passes at exactly 7 checks, which chance
predicts, and it does not read as English. The shuffled K4s give nothing. All 3 planted answers came back as the only
reading.

## The idea

K2 ends LAYER TWO. If K4 went through the K1/K2 chart (the KRYPTOS tableau, key ABSCISSA or PALIMPSEST) and also
through a second, different chart, then layer two never saw EASTNORTHEAST / BERLINCLOCK. It saw those letters after
or before the known step, so every earlier battery tested the wrong letters. Idea 84 had two layers, but only with two
repeating keys.

## What was run (`attacks/120_known_first_layer.py`, helpers in `kryptos/idea120_layer.py`)

* **Known layer:** KRYPTOS tableau (checked: it reproduces K1 and K2 exactly) or A-Z; keys ABSCISSA, PALIMPSEST,
  PALIMPCEST and KRYPTOS; adding or subtracting; every phase of the key at K4 letter 1. Two orders: known layer first
  (the clue plain letters are replaced by their layer-one letters) and known layer last (it is stripped from all of
  K4). That gives 280 variants. Each one is just a new set of 24 clue letter pairs.
* **Layer two:** the round-11 battery (repeating 1-17, sliding 1-15, progressive 1-12, autokey lags 1-6, chain addition)
  plus idea 104's fixes (every stacked pair exactly; autokey numbered on A-Z or KRYPTOS; progressive key moved on in
  another order). Five layouts, Vigenere and Beaufort, 7+ exact checks. Chance is 3.3e-8 passes per alphabet and
  variant.
* **Part 1:** all 280 variants on 19,622 alphabets (A-Z, KRYPTOS, theme and common words).
  **Part 2:** the 16 phase-0 KRYPTOS variants on the rest of the 666,993 dictionary alphabets. The plain ones ran in the
  main run (33 minutes) and the 446,675 transposition-mixed ones in a second run (`--mixed-only`, 27 minutes).

## Numbers

| run | pairs | 7+ passes | chance | best reading |
|---|---|---|---|---|
| K4 main | 8,705,296 | **0** | 0.29 | — |
| K4 mixed alphabets | 7,146,800 | 3 (all 7 checks, one event) | 0.24 | -8.25 |
| 3 shuffled K4s, main (1/9 slice each) | 967k each | 0, 0, 0 | 0.03 each | — |
| 3 shuffled K4s, mixed (1/9 slice each) | 794k each | 0, 0, 0 | 0.03 each | — |

The 3 mixed-alphabet passes share one setting: alphabet DULLARDNESS~keyed, PALIMPSEST deciphering, phase 0, known
layer last, with two stacked keys of p=5 and q = 14, 21 or 42. Those lengths are nested, so it is one coincidence.
The readings are gibberish (RUDTLADJBWNHD..., -8.25; English needs -5.1).

**Planted: 3/3.** Each was searched over all 280 variants and 303 alphabets, and only the true variant and alphabet
passed. The three were: ABSCISSA (phase 3, first), then a sliding key of 5; a progressive key of 7, then PALIMPSEST
(phase 4, last); ABSCISSA deciphering on A-Z (phase 5, first), then plain autokey lag 2. All three were read back
97/97, English -4.27 to -4.47.

## Scope limits

* Only these four known-layer words. There is no Beaufort-form known layer.
* The 264 variants whose key does not start at K4 letter 1 (and the A-Z phase-0 ones) ran only on the 19.6k small
  set. The full plan would have taken about 2 hours.
* Not covered: idea 104's gap, mod, multiplier, drop and word-break variants; hidden alphabets; running keys;
  transposition between the layers.
* The controls ran on 1/9 slices of the alphabets instead of 1/3, to keep the run near 30 minutes.

## Surprises

* None in the results.
* The cost is mostly idea 104's "progressive moved on in another order" test (about 75% of the time). It was rewritten
  with `bytes.translate`, which is 1.7x faster and gives the same answers (checked in `tests/test_idea_120.py`).

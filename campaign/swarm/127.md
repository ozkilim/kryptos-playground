# Idea 127: Gromark with one dictionary alphabet, the other free

**Verdict: dead in scope.** K4: 0 survivors. Controls: 2, 2, 0. Planted: 2/2 found and ranked first.

**The idea.** Gromark grows a short digit primer into a long key by chain addition, then shifts each
letter along a mixed alphabet by its digit. The straight A-Z plain side is already dead (Bean). With both
alphabets hidden it survives the clues but could only be judged by English completion (idea 41, about
50% power). K1 and K2 used keyword alphabets. So this run fixes one side to a dictionary keyword alphabet
and leaves the other side completely free. That makes the clue test exact. For side A (dictionary plain
alphabet), the 10 clue pairs with equal cipher letters must land on the same slot, and different cipher
letters on different slots. Side B is the mirror, with the 11 pairs of equal plain letters. A hash join
matches the alphabet's difference vector against the digit stream's, and then the distinct-slot rule is
checked exactly.

**What was run** (`attacks/127_gromark_one_dictionary_side.py`, 13 minutes, 12 processes):
* 666,993 dictionary and transposition-mixed keyword alphabets.
* 134,945,192 primers in bases 3-16:
  * Gromark taps, d_i = d_{i-n} + d_{i-n+1}: lengths 2-7, up to 20M primers per base and length. That
    covers every base-10 and base-11 primer up to 7 digits, and bases 12-16 up to 6.
  * Three-term taps and end taps: lengths 3-7, up to 5M per base and length.
* Additive and subtractive forms, both sides: 3.6e14 settings in all.

**Numbers.**
* **K4:** 2 signature hits, both failing the distinct-slot check. 0 survivors, so there is nothing to
  decrypt.
* **Controls:** 3 shuffled K4s, chosen to have at least 8 equal-cipher-letter clue pairs, close to K4's
  10. A plain shuffle often has only 5, which makes side A far weaker. They gave 2, 2 and 0 survivors.
  The best completions are gibberish at -6.71 (word cover 0.45 and 0.37).
* **Planted messages:** both were searched in the same pass against every alphabet and primer.
  * Base 10, 5 digits, WEALTHMONGER~keyed plain alphabet: found among 752 survivors. This plaintext
    happened to give only 6 equal-cipher pairs, so the join was weak for it. The completion still put the
    true setting first, at -4.48, reading back 94/97 letters (74 forced by the clues alone).
  * Base 12, mirrored, subtractive form, SLOSHER~cols cipher alphabet: found among 5 survivors. The other
    4 are neighbouring alphabets with the same primer. The true setting came first, 94/97 letters.
  * In the smoke run (6,002 alphabets) both read back 97/97.

**Scope limits.** Only the three tap rules and the primer sizes above. The digit is added straight to
the alphabet position. Not covered:
* both alphabets free;
* non-keyword alphabets on the fixed side;
* other taps or multipliers, or carries;
* a keyed digit-to-letter step;
* a transposition layer;
* a wrong clue letter.

**Surprising.** How strong the test is depends on how many letters repeat inside the clue blocks. K4 has
10 equal-cipher pairs, more than a typical shuffle (often 5). So for K4 the side-A test is close to
decisive: chance survivors are expected near 0, and none appeared.

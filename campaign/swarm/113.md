# Idea 113: Quagmire IV with both alphabets hidden, key of 8

**Verdict: no signal, and the test is weak.** K4 reads no better than shuffled K4s. But the planted answer was
recovered in only 1 of 4 cases, so this does **not** rule the idea out.

## The idea

Idea 99 showed that a repeating key of 1-7 or 9-12 cannot fit K4's clue letters with any fixed alphabet. Length 8
(ABSCISSA, the K3 grid width) is the one short repeating key left when both alphabets are free. At length 8 the clue
cipher letters fall into two pieces: 11 letters with slots 0-5 and 7, and G L Z with slot 6. There are 4 loops. With
both alphabets hidden, each loop is a check on the places of the 13 clue plain letters only:
2T+O = N+L+S, K+S+N = A+T+I, B+E = H+O, C+T = R+S (mod 26).

## What was run

`attacks/113_both_hidden_length8.py`, helpers `kryptos/idea113_both.py`, test `tests/test_idea_113.py`. The clue
pre-filter passes (score 1.0).

* **Exhaustive enumeration.** The 4 loops are solved for 4 letters. The other 8 letters run in generated nested
  loops, and plain and cipher places are checked for collisions as soon as they are known. Shifting everything, or
  multiplying everything by a unit mod 26, changes nothing, so one letter is fixed at 0 and another at 1, 2 or 13.
  Multiplying by -1 turns Vigenere into Beaufort, so both forms are covered by the same search.
* **Counts.** 118,611,979 survivors for the repeating key, and 52,480,393 for the sliding key with word sum 13.
  Both are below the idea's 2e8 limit.
* **Scoring.** Each survivor forces 45 positions of K4 (21 of them outside the clues). Each forced position gets a
  clue letter or "one of the other 13". Survivors are scored by an order-3 chain built from the big quadgram model.
  An earlier version that treated "other letter" as cheap had no power, and the fix is described in the code.
* **Completion.** The best 300 are completed by annealing the other plain letters, the other cipher letters and the
  offset between the two pieces on the big model.
* **Run time.** 24 minutes in all.

**Planted.** Four English messages, random alphabets on both sides, random key of 8, redrawn to K4's structure.
The true setting ranked 82 of 134M. It was completed and read back 87/97 letters at -4.35. The other three ranked
23,014, 1,820,268 and 336,474 (the last is the W=13 sliding plant), so they never reached the completion stage.
**0/4 ranked first and 1/4 recovered: the test lacks power.**

## Scope limits and surprises

* **Not an elimination.** About 21 scattered forced letters cannot single out one setting among about 1e8.
* **Completion overfits.** Completion has a lot of freedom: on planted texts, wrong settings complete to -4.7 to -4.8,
  better than K4's controls. So only a narrow top list can be judged.
* **Sliding sums not run.** Sliding keys with the other 24 word sums (odd and even classes) were not run, because each
  class costs 12 times the repeating search.
* **Run bugs.** A first run mistakenly used the same shuffled text for all three controls. It was fixed and rerun,
  and only the final run is in the ledger.
* **Better next step.** Use the 118M placings as a filter for keyword-ordered plain alphabets, where a strong prior
  would make the test decisive (see follow-ups).

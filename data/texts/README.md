# data/texts/

Drop plain-text files here (any `.txt`) and `attacks/04_running_key.py` will try every 97-letter
stretch of them as a K4 running key. Good candidates: Howard Carter's 1922 tomb diary (K3 paraphrases
it), Sanborn's statements, the Berlin Wall / Weltzeituhr inscriptions, the CIA memo texts tied to the
sculpture. Only public-domain or freely licensed text, please.
